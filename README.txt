MultiFix MVP site (static)

What’s included:
- index.html (Home)
- owners.html (For Owners / Plex)  <-- NEW
- services.html, gallery.html, about.html, contact.html
- css/style.css
- js/lang.js (EN/FR/UA)

How to deploy to shared hosting:
1) Upload all files/folders to public_html/
2) Enable SSL (AutoSSL / Let’s Encrypt in cPanel)
3) Open the site in a phone browser and test language switch

Note about the contact form:
- Current form uses "mailto:" (no backend).
- If you want a real form without backend, replace form action with a service like FormSubmit or enable Netlify Forms (if using Netlify).
